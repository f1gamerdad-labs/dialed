Your first five minutes

  1. Open Dialed before you start your sim. Windows asks for permission when it opens, and that prompt can freeze a full-screen game.
  2. Windows may say "Windows protected your PC" because Dialed is not signed yet. Click More info, then Run anyway.
  3. Pick iRacing or Le Mans Ultimate, run three captures in the same busy session, then press Analyse.
