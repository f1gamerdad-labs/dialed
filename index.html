    A good test session

    Test where your PC works hardest, and use exactly the same session for every capture so the rounds compare fairly. The busiest moment is usually the first lap with a full field.

      Starts it through Steam with Dialed already open, so the Windows permission prompt cannot freeze the game. Then set up the session above yourself: games do not let other programs pick the track and cars.

      Capture

      Before you capture, close as many other programs as you can. That means OBS, Chrome and other browsers, Discord, overlays, and anything running in the system tray (check the arrow by the clock). Background programs are the most common cause of stutter and they skew your results.

      Open this app before you start the sim. Windows asks for permission when the app opens, and that prompt can freeze a full-screen game. Once the app is open, you never see it again, and the hotkey works from inside the game.

      Click Start capture, or press the hotkey while you are in the sim. You get a 10 second countdown with beeps, then 60 seconds are recorded, then two beeps. Drive (or watch a replay) with the same track, car and field each time.

            Backups and restore

            Before every change, the app saves your old file into a folder called Dialed Backups next to the sim's own settings, for every sim. Restore any of them here. Your current file is backed up first, so a restore can be undone too.

            Dialed by F1GamerDad

            Sim graphics, dialed.

            Settings built from your own PC, not copied from someone else's. It records your frame data with PresentMon and reads your sim's graphics settings, works out whether your processor, graphics card or graphics memory is holding you back, and suggests the changes that help most for the least visual cost.

            Not for VR. This tool is for monitors, single screen and triples. For VR, use NextLevelXR, which is built for it.

            Private. Everything runs on your PC. Nothing is uploaded.

            Small steps. Apply a few changes, capture again, and the tool tells you what each round did and what to put back.

            Frame capture uses Intel PresentMon, released under the MIT licence. Made by F1GamerDad.

            Report a problem

            What goes in the report

            • Always: the app's log (your Windows user name is blanked out of file paths), version numbers, your Windows and graphics card names.

            Your message and a short summary go straight to F1GamerDad. The full report is saved as a zip file in Documents\Dialed\Reports and the folder opens, so you can drop the zip into Discord or an email if asked. The zip is never uploaded by the app.
